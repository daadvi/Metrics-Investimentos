# Roadmap por prioridade

## Entregue na v0.2

- [x] Carteira manual e histórico local
- [x] Importador XLSX/CSV B3 com confirmação, revisão e deduplicação
- [x] PDF/TXT com extração de texto para IA, sem OCR
- [x] SQLite ACID com migração do JSON antigo
- [x] Criptografia opcional por senha de inicialização
- [x] Lista de desejos, preços manuais e eventos de dividendos
- [x] Fichas de ativos manuais com fontes
- [x] Proventos por ticker e mês
- [x] Simulador com múltiplas fases, reinvestimento parcial, inflação
- [x] IA local, chave própria e modo gratuito sem LLM
- [x] Exportações CSV e backup/restauração JSON
- [x] Atalho Linux de janela de aplicativo (Node + navegador)

## Próximas versões (não concluídas)

- [ ] Pesquisa oficial automática de informes CVM/FNET e fatos relevantes
- [ ] Sistema de RAG com extração estruturada e citações por página
- [ ] Cotações externas com fornecedor licenciado e indicador de defasagem
- [ ] Cálculos tributários auditáveis por exercício, situação e classe
- [ ] XIRR/TWR e indicadores avançados robustos
- [ ] Eventos societários, ETF, renda fixa e multi-moedas detalhados
- [ ] Dashboards avançados e comparador de ativos estruturado
- [ ] Empacotamento Tauri nativo para Linux/Windows/macOS
- [ ] Android e voz com permissão explícita
- [ ] Backup criptografado automático e gerenciador de senhas no app
- [ ] Bateria completa de testes E2E no navegador real e revisão de segurança

## Limitações comerciais

Orçamento fixo R$ 50. API de dados premium e backend sempre ativo não podem ser assumidos gratuitos. Todo o projeto continua local-first e open source, sem operação automática de ativos.
